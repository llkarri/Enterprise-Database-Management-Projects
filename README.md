### 2. Assignment 3: ETL Pipeline & NoSQL Implementation
**Role:** Data Engineer  
**Focus:** Q3 2024 Data Migration  
**Tools:** Python (Pandas/PyMongo), MongoDB Atlas, KNIME, Dune API

*   **Objective:** Built an automated ETL (Extract, Transform, Load) pipeline to migrate crypto financial data from a raw API source to a NoSQL database.
*   **Key Activities:**
    *   **Data Extraction:** Developed a Python script to fetch Q3 2024 transaction data via the Dune Analytics API.
    *   **Data Loading:** Configured a **MongoDB** cluster and programmatically uploaded thousands of transaction records using `pymongo`.
    *   **Data Processing:** Utilized **KNIME** to connect to MongoDB, perform join operations on Yelp dataset my_restaurant of it's business and review data, and filter unstructured data for business insights.
